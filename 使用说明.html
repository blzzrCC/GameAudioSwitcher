🎧 游戏音频自动切换 · 使用说明

功能：当检测到 无畏契约 或 暗区突围:无限 的游戏本体运行时，自动将系统默认输出设备（含语音通信设备）切换为 耳机；游戏全部关闭后，自动恢复为 扬声器。也支持随时手动切换与全局快捷键切换。

开机切换（新增）：程序启动（含开机自启）时，自动把系统默认输出切到你指定的设备 —— 在托盘菜单「开机时切换至」中选 扬声器 / 耳机 / 不切换，详见第三节。

形态：托盘常驻应用 —— 启动后驻留系统托盘（任务栏右下角），右键图标可退出，退出后进程完全结束、不占用后台。

新用户提示：首次运行会自动检测配置中的设备是否存在于本机；若对不上，程序会自动弹出「扫描音频输出设备」窗口，一键识别耳机与扬声器，无需手工填写设备名。配置文件与日志也会在首次运行时自动生成。

一、文件清单

文件说明

build.bat + 源码 *.cs编译脚本与源码（如需重新编译）

二、使用方法

1. 双击 GameAudioSwitcher.exe 启动（桌面双击或固定到任务栏均可）。首次运行会在同目录自动生成 config.ini 与 GameAudioSwitcher.log。
2. 程序驻留托盘，图标为耳机图案（耳机 + 双向切换箭头）。此时开始自动监测。
3. 首次使用先确认设备：若程序提示「未找到配置中的音频设备」，会直接弹出扫描窗口 —— 点「自动识别」→「保存并应用」即可（详见第四节）。配置本就正确时不会打扰你。
4. 打开无畏契约 / 暗区突围:无限 —— 检测到游戏本体进程后约 2 秒内自动切到耳机，托盘弹出提示。
5. 关闭游戏 —— 自动恢复扬声器。
6. 右键托盘图标打开菜单，功能如下：
菜单项说明
状态：…当前运行状态与最近一次操作结果
扫描音频输出设备…自动扫描本机全部输出端点，并自动识别耳机 / 扬声器，一键生成配置（新用户首选）
立即切换输出设备点击后立即在 耳机 ↔ 扬声器 之间切换
设置切换快捷键…弹出窗口，按下组合键即可自定义全局快捷键（默认 Ctrl+Alt+H，可留空关闭）
开机自启勾选 = 登录 Windows 时自动运行（需勾选此项，「开机时切换至」才能随开机生效）
开机时切换至：…新增：程序启动时自动把系统默认输出切到所选设备 —— 子菜单选「扬声器」/「耳机」/「不切换（跟随系统）」，默认「扬声器」，点选后立即写入 config.ini
自动切换：已开启 / 已暂停总开关：取消勾选暂停「检测游戏并自动切换」，程序仍驻留；恢复勾选后自动校正回应有状态（有游戏→耳机 / 无游戏→扬声器）
退出结束程序，完全释放后台

全局快捷键在任何界面都生效（含全屏游戏），且不受「自动切换」暂停影响。

7. 快捷键手动切换：按 Ctrl+Alt+H（默认）即切到另一个输出设备 —— 当前是耳机则切扬声器，反之切耳机。

三、开机自动切换设备（新增）

作用

开机后 Windows 有时会自己挑一个默认输出设备（上一块用过的声卡、显示器 HDMI 等），导致开机没声音或声音走错地方。开机切换让程序在启动时主动把默认输出切到你指定的设备。

怎么设置

1. 右键托盘图标 → 展开「开机时切换至：…」子菜单。
2. 选 扬声器（默认）/ 耳机 / 不切换（跟随系统） —— 点一下即生效并写入 config.ini，无需重启程序。
3. 若希望开机时就自动生效，还需在同一菜单勾选「开机自启」；否则只有手动启动程序时才会执行一次切换（程序会气泡提示这一点）。

执行规则

情况行为
设置为「不切换」完全不改变系统默认输出设备（等同旧版本行为）
目标设备不可用跳过切换并在托盘提示，不强行接管（不会切到无声设备上）
当前输出已是目标设备不做任何操作，日志记录「无需切换」
启动时检测到游戏正在运行跳过，交由「自动切换」处理（避免把游戏声音切回扬声器）
正常情况启动约 1.2 秒后切换并弹出气泡提示

该逻辑与「自动切换」总开关相互独立 —— 即使暂停了自动切换，开机切换仍会照常执行。

四、新用户配置设备（自动扫描）

什么时候用

换新电脑、重装系统、换了耳机/音箱，或程序提示「未找到配置中的音频设备」时。这个功能的作用是：不必再去「系统声音设置」里手工抄写设备名称。

操作步骤

1. 右键托盘图标 → 点「扫描音频输出设备…」（首次运行若设备对不上会自动弹出该窗口）。
2. 窗口列出本机全部输出端点（名称 / 状态 / 是否当前默认），并已按「可用优先、默认优先」排序。
3. 点「自动识别」：程序按名称关键字（耳机 / Headphone / Headset…、扬声器 / Speaker…）自动填好「耳机」与「扬声器」两栏。
4. 也可手动指定：在列表中选中一行 → 点「设为耳机」或「设为扬声器」。
5. 点「测试切换到所选设备」当场验证能否切换成功（系统默认输出会真的切过去）。
6. 点「保存并应用」—— 写回 config.ini 并立即生效，无需重启程序。

界面元素说明

元素说明
只显示可用设备默认勾选。取消勾选可看到历史遗留的失效端点（显示为灰色「不存在」），一般无需理会
重新扫描插拔设备后点一下刷新列表
自动识别按名称关键字一键推定耳机 / 扬声器配对
设为耳机 / 设为扬声器把列表中选中的设备填入对应栏位
测试切换到所选设备立即把系统默认输出切到该设备，用于验证
保存并应用保存到 config.ini，并立即对运行中的程序生效

保存时会做校验：若所填设备不在扫描结果中或当前不可用，会先给出警告并请你二次确认，避免存下一个永远切不过去的设备名。

六、配置文件说明（config.ini）

[devices] headphone=耳机 (Realtek(R) Audio) ← 游戏时切换到的设备（与系统声音设置名称一致） speaker=扬声器 (Realtek(R) Audio) ← 无游戏时的设备 [settings] poll_interval_ms=2000 ← 检测间隔（毫秒，最小 500） balloon=1 ← 切换气泡提示（1 开 / 0 关） hotkey=Ctrl+Alt+H ← 全局切换快捷键（留空 = 禁用；可在托盘菜单弹窗修改） startup_switch=speaker ← 程序启动（含开机自启）时自动切换到的设备 ← speaker=扬声器 / headphone=耳机 / none=不切换 ← 仅在没有游戏运行时执行；可在托盘菜单「开机时切换至」修改 [games] processes=VALORANT-Win64-Shipping.exe;VALORANT.exe;UAGame.exe;ABInfinite-Win64-Shipping.exe;ABInfinite.exe ← 游戏本体进程名，分号分隔，任一存在即视为游戏运行中 ← 暗区突围:无限 国服(WeGame)本体进程为 UAGame.exe

修改 config.ini 后需重启程序生效（托盘菜单改快捷键 / 开机切换目标则立即生效并自动写回本文件）。本文件与日志均由程序首次运行时自动生成。

七、注意事项

  • 耳机需保持插入：耳机端点不可用（未插入 / 被禁用）时，程序会跳过切换、不强行接管，避免无声。
  • 设备名自动容错：系统中存在同名音频端点时，Windows 会给设备名加序号（形如 耳机 (N- Realtek(R) Audio)，N 为系统分配的消歧序号）。程序匹配时会自动忽略该序号，因此 config.ini 保持「耳机 (Realtek(R) Audio)」这类基础名称即可，驱动重装或设备插拔后通常无需修改。用「扫描音频输出设备」保存时会写入当前实际名称（含序号），同样具备这层容错。
  • 开机切换需配合「开机自启」：开机切换在程序启动时执行。若未勾选「开机自启」，程序不会随 Windows 启动，该项设置只在手动双击运行时生效。
  • 配置文件与日志自动生成：二者不随仓库分发，程序首次运行时会自动在 exe 同目录创建；删除后再次运行会重新生成（配置回到默认值，需要重新指定设备）。
  • 首次运行自动引导：若配置中的耳机与扬声器在本机都匹配不到可用端点，程序启动约 1 秒后会自动弹出扫描窗口（仅此一种情况会主动弹窗，日常不会打扰）。
  • 切换策略：仅在「游戏启动 / 游戏关闭」瞬间自动切换；游戏运行期间你手动切换设备不会被干预（边界切换模式）。
  • 暗区突围进程名：国服 WeGame 版本体进程为 UAGame.exe（国际版为 ABInfinite-Win64-Shipping.exe / ABInfinite.exe），均已内置。若游戏更新后进程名变化，查看任务管理器确认后修改 config.ini 的 processes= 即可，无需重新编译。
  • 若移动 exe 位置：需要重新在托盘菜单勾选一次「开机自启」（启动项指向旧路径会失效）。
  • 快捷键规则：需包含 Ctrl / Alt / Shift 之一（或单独使用 F1-F24），避免误触；若提示注册失败，说明该组合已被其他程序占用，换一个即可。
  • 多开保护：重复启动只会提示已在运行，不会重复占用。
  • 图标：EXE 与托盘图标均已换成耳机图案（耳机 + 双向切换箭头）；日志中会记录实际生效的图标来源（「托盘图标已加载，来源：嵌入资源 AppIcon.ico…」），可据此确认。
